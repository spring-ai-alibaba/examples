## 背景

spring-ai-alibaba-examples 项目是一个多模块的 Spring AI Alibaba 示例代码库，包含了从基础到高级的各种 AI 应用示例。

### 项目现状
- 项目包含 20+ 个子模块，涵盖聊天模型、RAG、智能体、MCP 等多个领域
- 部分模块提供了 Web REST API 接口供测试和演示
- 一些模块缺少完整的文档说明，影响开发者理解和使用

### 需要完成的任务

#### 1. HTTP 接口文档生成
**目标**：为包含 Web 接口的模块生成 `.http` 文件

**适用模块**：
- 提供 REST API 的 Spring Boot 应用模块
- 具有控制层（Controller）的模块
- 需要测试接口调用的模块

**生成内容**：
- GET、POST、PUT、DELETE 等常用 HTTP 方法示例
- 包含必要的请求参数和请求体
- 提供示例数据和说明注释

#### 2. 模块文档完善
**目标**：为缺少 README.md 的模块生成文档

**适用模块**：
- 没有 README.md 文件的模块
- README 内容不完整或过时的模块

**文档内容应包含**：
- 模块功能概述和用途说明
- 主要特性和技术栈
- 配置要求和依赖说明
- 快速开始指南
- API 接口说明（如适用）
- 示例代码和使用场景

### 执行方式
使用 Claude Code 的内置技能：
- 调用 `http-generate` 技能生成 HTTP 接口文档
- 调用 `module-generate` 技能生成模块 README 文档

### 期望成果
提升项目文档完整性，帮助开发者：
- 快速理解各模块功能和用途
- 方便测试和调试 Web 接口
- 降低学习和使用门槛
